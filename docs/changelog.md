## v1.0.6 · 2026-11-06

- 回退 v1.0.5 新增的测试代码、CI 验证步骤及相关说明，保留 TCP Flags、桌面手动检测和单 EXE 分发功能。

## v1.0.5 · 2026-11-06

- 桌面版增加手动检测入口，关闭自动检测后仍可检测当前服务器，任务期间避免重复触发。
- 桌面与 Web 版新增整条敲门序列共用的 TCP Flags，支持 SYN、ACK、FIN、RST、PSH、URG，多选、快捷组合及发送预览；旧配置默认 SYN，UDP 和业务端口检测不受影响。
- 桌面主界面显示已保存的 Flags；批量设置替换序列时同时替换 Flags，保留各服务器原有的间隔与时间上限。
- Windows x64 通过单 EXE 内嵌 WinDivert，使用自定义 Flags 时按需释放、校验并加载，需要管理员权限；包含许可证、对应源码及提取命令。默认 SYN 不加载驱动。
- Linux 自定义 Flags 使用原始套接字，需要 CAP_NET_RAW；权限不足时在发送任何步骤前报错，不进入后续业务检测。macOS 当前仍支持默认 SYN。
- Web 编辑弹窗按新设计调整分组和滚动布局，支持步骤排序；详情页展示 Flags。容器为非 root 服务配置 NET_RAW 文件能力，同步更新部署文档。

## v1.0.4 · 2026-11-04

- Web 自动检测改为由前端定时触发，仅在已登录、网页可见且开启自动检测时运行；后台、关闭网页或退出登录后暂停。
- 移除 Web 后端独立周期检测任务，已发起的检测及敲门任务正常结束，手动检测继续可用。
- 前端计算下次检测倒计时，按设置的范围和间隔发起检测，避免任务重叠；增加对应回归检查并接入 CI。
- Compose 通过 `.env` 直接加载程序配置，固定容器名为 `opensesame`，同步更新部署文档。

## v1.0.3 · 2026-11-03

### 新增

- 增加 Rust + Axum Web 版，内嵌 HTML、CSS、JavaScript 和字体，提供 Linux amd64 发行包。
- SQLite 保存服务器、勾选状态和设置，支持访问密码及可选 Google 登录。
- 单台和批量开门按真实发送进度显示路径、节点和流光进度条，默认端口为 `18010`。
- 增加 GHCR 镜像构建、Compose 配置和程序内健康检查，镜像复用发行二进制。
- 浏览器控制台显示青色版本标签、8 位提交短号和版权信息。

### 修复与体验

- 修复列表菜单裁切、检测状态更新和页面刷新主题闪烁，默认使用亮色。
- 空闲每 10 秒同步状态，任务中每秒同步；敲门进度通过 SSE 逐步推送。
- 检测中图标持续旋转，开门端点文字居中，再次开门立即清零进度。
- 最近记录最多保留 10 条；发送失败立即显示错误，不再触发关联端口检测。
- 普通文字使用默认箭头光标，输入框保留编辑光标。

## v1.0.2 · 2026-11-02

### 新增

- 服务器清单增加全选框和已选数量，支持未选、部分选中和全选三种状态。
- 勾选变更即时保存，重启后恢复；删除服务器时清理对应记录，旧配置默认未勾选。

### 修复与体验

- 默认字号下，左侧服务器条目由 74 px 收紧至 64 px，协议标签与状态行的右边缘对齐。
- 批量开门结果改为“服务器 / 敲门进度 / 端口状态”三列表格，表头高 36 px，每行高 64 px。
- 表格行独立滚动，表头、页头、完成提示和返回按钮保持固定；检测时间与补充说明在状态下方显示。
- 保存勾选失败时保留原选择并显示错误，恢复时忽略已不存在或重复的服务器 ID。

### 验证与文档

- 增加全选点击、取消全选、持久化恢复、删除清理和保存失败验证，并提供多行表格及滚动预览。
- 更新使用指南、配置参考和开发指南。

## v1.0.0 · 2026-11-01

首个正式版本，提供 Windows x64、Linux x64 / ARM64、macOS Intel / Apple Silicon 应用。

### 新增

- Rust + Slint 跨平台桌面客户端，支持 TCP / UDP 混合敲门序列及独立业务端口配置。
- 多服务器管理、单台开门、批量开门及每台进度和结果展示。
- 启动自动开门、全部或当前服务器的持续检测，以及开门后的单次检测。
- 分别批量更新开门序列与业务端口，先验证整批配置后保存。
- 按 Windows / Linux / macOS 规范保存配置，上次服务器选择恢复、深浅主题与跟随系统。
- 简体中文、English 与系统语言，保存后立即更新界面、状态和提示。

- 增加 Linux x64 / ARM64、macOS Intel / Apple Silicon 支持目标，统一配置格式与现有操作。

### 修复与体验

- 调整编辑窗口校验提示、协议标签对齐及连接状态图标，按界面设计呈现。
- 内嵌字体、Windows EXE 图标和 macOS app 图标，采用 FemtoVG 渲染版本。
- 同一 IP 的敲门及检测互斥，周期检测不重叠，过期异步结果不覆盖当前配置状态。
- 读取异常配置时保留原文件并禁止覆盖写入。

### 构建与文档

- 整理项目首页、文档中心、使用、部署、二进制、开发、配置和发布说明。
- 提供分支与 PR 常规检查、按需依赖审计、五平台打包及版本标签发布。
- 发行包附 SHA-256、使用说明和字体授权；先建 Release 草稿，重新下载验证后公开。
