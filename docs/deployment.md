# 部署指南

[文档中心](README.md) · [使用指南](usage.md) · [二进制说明](binary.md) · [发布流程](releasing.md)

OpenSesame 是 Windows、Linux 和 macOS 桌面客户端。此处介绍安装、配置维护与故障排查；服务端 knockd 的安装和防火墙规则由服务器管理员维护。

[运行要求](#运行要求) · [安装](#安装与首次运行) · [备份](#备份与恢复) · [升级](#升级与回退) · [排查](#故障排查)

## 运行要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 x64；Linux x64 / ARM64；macOS Intel / Apple Silicon |
| 程序 | 对应架构的原生程序或 macOS `.app` 应用 |
| 运行环境 | 无需安装 Rust、.NET 或 WebView2，程序字体与资源已内嵌 |
| 图形环境 | 默认使用 FemtoVG，需可用的 OpenGL 图形驱动；Linux 需 X11 / Wayland 桌面及相应系统库 |
| 权限 | 普通用户运行，用户配置目录可写；无需原始套接字权限 |
| 网络 | 可访问目标服务器，出站 TCP / UDP 及 DNS 未被本机策略拦截 |

Linux 以 Ubuntu 22.04 构建，目标基线为 glibc 2.35；不提供 Alpine / musl 包。macOS 的构建最低目标为 12.0，旧版本实机兼容性仍需验证。CI 执行常规检查和原生构建，各发行版、显卡及系统版本的运行兼容性需实机验收。

macOS 包只有临时签名，尚未进行 Developer ID 签名或公证，首次打开可能受到系统安全检查限制。可按系统提示在“隐私与安全性”中允许打开；正式签名与公证需要另行配置开发者凭据。

macOS 15 起访问局域网服务器可能需要本地网络权限，应用包已包含用途说明。若系统询问，请按使用需要授权，也可在“隐私与安全性 → 本地网络”中调整。详见 [Apple 本地网络隐私说明](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)。

不提供安装服务、后台守护或开机任务。启动自动开门指打开此程序时执行。

## 安装与首次运行

1. 按[二进制说明](binary.md#下载与校验)下载、校验并解压程序。
2. 在可保留的位置运行 `OpenSesame.exe`，按[使用指南](usage.md#服务器管理)添加服务器。
3. 核对服务端序列的端口、协议、顺序、时间要求，以及要检查的业务端口。
4. 手动开门并确认结果，再按需要开启自动行为。

程序可放在任意目录，配置不会随着工作目录变化。同一用户下的多个程序副本共用配置，建议只运行一个实例。

| 系统 | 配置文件 |
| --- | --- |
| Windows | `%APPDATA%\OpenSesame\config.json` |
| Linux | `$XDG_CONFIG_HOME/OpenSesame/config.json`，未设置或不是绝对路径时使用 `~/.config/OpenSesame/config.json` |
| macOS | `~/Library/Application Support/OpenSesame/config.json` |

## 备份与恢复

退出程序后备份上述平台配置目录中的 `config.json`。文件包含服务器名称、地址、敲门序列、业务端口和应用设置，采用明文 JSON 保存；共享前应移除个人服务器信息。

恢复时先退出程序，再把备份复制到相同路径。迁移到其他用户或计算机时，复制到目标用户在该平台的配置目录。手动修改配置前应保留备份，字段含义见[配置参考](configuration.md)。

配置损坏或版本不受支持时，程序保留原文件并显示错误，禁用写入以避免覆盖。退出程序后修复文件，或先移走损坏文件再重新添加服务器；不要在程序运行时替换配置。

## 升级与回退

1. 退出所有 OpenSesame 窗口，备份配置及当前应用。
2. 下载新版本并核对 SHA-256，解压到新目录或替换原程序。
3. 重新打开程序，检查服务器清单、语言和检测设置，再测试一次开门。

回退时退出程序，换回旧应用；如果配置格式发生变化，同时恢复与该版本对应的备份。版本变化见[更新记录](changelog.md)。第一版的配置版本为 `1`。

卸载只需退出并删除程序目录。若也要清除个人配置，另行删除对应的 `OpenSesame` 配置目录；保留此目录可在下次运行时恢复设置。

## 故障排查

| 现象 | 检查方向 |
| --- | --- |
| 无法启动或窗口异常 | 核对系统和 CPU 架构，更新显示驱动，确认程序完整且未被本机安全策略阻止 |
| 提示额外 DLL 或系统图形库缺失 | Windows 重新下载完整包并核对校验值；Linux 按二进制说明安装系统图形库 |
| 名称解析失败 | 核对域名、DNS 和当前网络；地址中不要带协议、路径或端口 |
| 序列已发送，TCP 仍不可连接 | 核对顺序、协议、步骤间隔、服务端序列超时及 `TCPFlags = syn`；确认业务服务监听目标端口 |
| 更换网络后无法开门 | 核对公网出口 IP、VPN、NAT 和服务端允许来源，必要时查看 knockd 日志 |
| UDP 一直无法确认 | 空探测可能不被服务响应；用实际业务客户端确认，不能据此判断规则没有放行 |
| 批量设置保存失败 | 查看被点名服务器的步骤间隔、序列总时限和新序列长度，整批验证通过后才会保存 |
| 修改默认周期后部分服务器未变化 | 已单独设置的时间会保留，默认值只更新仍使用旧默认时间的服务器 |
| 配置无法保存 | 检查用户配置目录写权限、磁盘空间及配置错误提示；损坏文件会被保留并禁止覆盖 |

开门结果还受服务端匹配规则、临时放行时长和业务服务本身影响。客户端不会自动续发开门序列，周期检测仅发送业务端口探测。
