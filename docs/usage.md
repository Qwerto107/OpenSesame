## knockd 工作机制

knockd 是运行在服务器上的“敲门”守护进程，通过抓包识别约定的端口访问序列，再执行服务端配置的命令。OpenSesame 负责发送序列和检测端口，放行规则由服务端决定。

1. 服务器防火墙平时限制 SSH 等业务端口的访问，业务服务本身仍可正常运行。
2. 客户端按约定顺序发送 TCP / UDP 报文，例如 `7000/TCP → 8000/UDP → 9000/TCP`。
3. knockd 在规定时间内识别同一来源 IP 的端口、协议和顺序，满足 TCP 标志等匹配条件后执行命令，通常仅允许该来源 IP 访问指定业务端口。
4. 客户端再检测业务端口，用户随后使用 SSH 等业务客户端连接并正常认证。

敲门端口不必开放或运行服务，因为 knockd 观察的是到达服务器的报文，不要求敲门建立连接。若报文在云安全组或前置防火墙被提前丢弃、未到达监听网卡，knockd 就无法识别。

序列匹配时限与端口放行时长是两回事。放行多久、是否通过超时或关门序列回收，由服务端规则决定；OpenSesame 的周期检测只探测业务端口，不会自动续发敲门。当前客户端只提供开门操作，业务服务仍需自身认证。

更多细节见 [knockd 手册](https://manpages.ubuntu.com/manpages/jammy/man1/knockd.1.html)。

## 服务器管理

点击左侧“新增”，填写名称、地址、开门序列和业务端口。地址只填写 IP 或域名，不带 `http://`、端口后缀或路径；IPv6 地址直接填写地址本身。

| 项目 | 作用 |
| --- | --- |
| 名称 | 用于清单和批量结果的显示名称 |
| 地址 | 服务端 IP 或域名，解析时优先 IPv4，也接受 IPv6 |
| 开门序列 | 至少一个步骤，每步独立选择 TCP / UDP 和端口，严格按顺序发送 |
| 步骤间隔 | 相邻步骤之间的等待时间，单位毫秒 |
| 序列时间上限 | 整次序列允许的总时间，必须足够容纳全部步骤 |
| 业务端口 | 开门后需要检查的端口与协议，独立于敲门步骤 |
| 检测时间 | 此服务器的周期与超时，可使用默认值或单独调整 |

保存后选择该服务器，右侧展示其序列与端口状态。通过“编辑”修改配置，“删除”移除服务器。详细范围见[配置参考](configuration.md#服务器字段)。

## 开门与检测

点击“开门”后依次发送序列，进度条展示已发送的步骤。发送完成后，客户端自动检查一次业务端口，即使已经关闭周期检测，也会进行本次检查。

“序列已发送”只说明客户端已完成发送，服务端是否放行以端口检测和实际业务连接为准。敲门端口本来就可能拒绝连接或无响应，不能将其当作发送失败；目标端口的“可连接”也不代表 SSH、数据库等服务已登录成功。

| 状态 | 含义 |
| --- | --- |
| TCP 可连接 | 已成功建立 TCP 连接 |
| TCP 不可连接或超时 | 本次连接未建立，可能与规则、网络或业务服务有关 |
| UDP 有响应 | 空 UDP 探测收到了目标端口的回复 |
| UDP 无法确认 | 在超时时间内没有收到回复，不能认定端口关闭 |
| 网络错误 | 地址解析或套接字等操作出现了明确错误 |

UDP 服务通常需要符合其协议的请求才会回复。目前不支持自定义文本 / HEX 探测和响应匹配。

## 自动行为

设置中的自动开门与自动检测相互独立。

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 启动自动开门 | 关闭 | 打开程序后，为上次选中的服务器发送一次序列；没有有效选择时不执行 |
| 自动检测 | 开启 | 程序打开后即可持续检测，不要求先点击开门 |
| 检测全部服务器 | 开启 | 周期检测所有服务器；关闭后只检测当前服务器 |
| 默认检测周期 | 30 秒 | 检测结束后等待该时长，再执行下一次 |
| 默认检测超时 | 3 秒 | 限制单次业务端口检测的等待时间 |

右侧业务状态区也可切换自动检测。关闭自动检测会停止安排后续周期任务，手动开门后的单次检测继续生效。

修改默认时间时，原来等于旧默认值的服务器会跟随更新；已经单独设为其他数值的服务器保留其设置。周期检测不会重叠。同一 IP 的敲门及业务检测依次执行，避免检测报文或其他敲门序列干扰服务端匹配。

## 批量操作

勾选左侧多台服务器后，底部显示已选数量，并提供“批量设置”和“批量开门”。

| 操作 | 影响范围 |
| --- | --- |
| 仅设置开门序列 | 替换选中服务器的步骤，保留各自的间隔、总时限和业务端口 |
| 仅设置业务端口 | 替换端口及协议，保留开门序列和检测时间 |
| 同时设置两项 | 分别应用上述修改，保留名称、地址等其他信息 |
| 批量开门 | 为选中的服务器执行开门及一次端口检测，展示每台结果 |

批量设置先验证所有选中服务器。如果新序列与某台原有的总时限不匹配，整批不保存，需先调整该服务器的时间设置。解析到相同 IP 的服务器排队执行，不同 IP 可以并行。

## 外观与语言

“设置”支持浅色、深色和跟随系统。语言支持简体中文、English 和跟随系统，保存后立即生效；服务器名称和用户输入不进行翻译。系统语言不匹配已支持的语言时回退为 English。

配置自动保存至当前用户的[平台配置目录](configuration.md#配置位置)，备份与迁移见[部署指南](deployment.md#备份与恢复)。
